# Как работают LLM — интерактивный курс

Обучающий сайт о больших языковых моделях: 10 разделов с текстом, интерактивными виджетами и 3D-сценами с пошаговыми экскурсиями. Все демонстрации считаются в браузере на маленьких «игрушечных» моделях (n-граммная модель, BPE на 90 словах, сконструированные эмбеддинги) — без серверов и внешних API.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

Другие команды: `npm run build` (typecheck + сборка в `dist/` + копия `404.html` для SPA-фолбэка на статическом хостинге), `npm run preview`, `npm test` (vitest для `src/lib`), `npm run lint`, `npm run typecheck`.

В dev-режиме первая загрузка каждой 3D-сцены занимает несколько секунд: Vite компилирует чанк на лету. В собранной версии сцена появляется примерно за 0,3 секунды.

Требуется Node ≥ 22.12.

## Структура

```
src/
  app/            маршруты, layout, сайдбар, главная, 404
  sections/       registry.ts (единый список разделов) + папка на раздел с виджетами
  scenes/         3D-сцены (react-three-fiber), store.ts — zustand-стор сцены и шаги экскурсии
  components/ui   Callout, Term (глоссарий-поповер), Formula (KaTeX), Slider, WidgetFrame, …
  components/charts   SVG-графики: BarChart, Heatmap, LineChart
  components/three-shell  оболочка сцены БЕЗ импортов three (ленивая загрузка, экскурсия, защита от перехвата скролла)
  components/three        Canvas, CameraControls, подписи (drei Html), анимационные помощники
  data/           корпус, BPE-корпус, эмбеддинги, примеры внимания, глоссарий, пресеты
  lib/            чистые функции: softmax, sampling, n-gram, bpe, embeddings, params, landscape (+ тесты)
```

Стек: Vite 8, React 19.2, TypeScript, three.js + @react-three/fiber + drei, react-router, zustand, KaTeX, Radix UI (поповеры). three.js попадает только в ленивый чанк сцен и загружается при первом появлении 3D на экране.

## Система подсказок

- `Callout` — блоки «Подсказка», «Попробуйте», «Важно» по ходу текста.
- `Term` — термины с пунктирным подчёркиванием; по наведению (на touch — по нажатию) открывается определение из глоссария и ссылка на раздел.
- `WidgetFrame` — у каждого виджета кнопка «?» с объяснением, что здесь крутить, и «Сбросить».
- 3D-сцены — hover-подписи объектов, кнопка «Экскурсия» с пошаговым туром (текст + перелёт камеры + подсветка), подсказка по управлению, клавиши ← → и Esc.
